# Enterprise Operations AI Assistant

## Overview

A simple multi-agent business automation platform for NovaTech Solutions Pvt. Ltd.

## Project Objective

The project aims to develop an AI assistant capable of supporting enterprise operations through specialized agents, company knowledge, tools, workflows, and a Streamlit interface.

## Technology Stack

- Python
- uv
- Jupyter Notebook
- LangChain
- OpenRouter
- Streamlit
- ChromaDB
